About Me

Hi, I'm Anthony Njenga. I'm an aspiring systems and performance engineer with a deep interest in computer architecture and GPU computing.

I'm passionate about writing low-level software that extracts maximum hardware efficiency — from cycle-accurate CPU microarchitecture simulations and hardware logic design in modern C++ to high-throughput CUDA kernels and deep learning systems from scratch.

I'm aspiring to work in Systems & Performance Engineering, High-Performance Computing (HPC), and GPU Kernel Engineering.

What I Work On

  • Computer Architecture & CPU Simulation — Designing and modeling processor microarchitectures in C++20: superscalar out-of-order execution, branch prediction, fetch/dispatch units, Reorder Buffers, Issue Queues, and Physical Register Files.
  • GPU Computing & CUDA — Writing and profiling high-throughput CUDA kernels on NVIDIA hardware. Parallel prefix scans, reductions, and memory coalescing optimizations.
  • Digital Logic & Hardware Modeling — Simulating fundamental hardware building blocks from the ground up: wires, tri-state buses, clock domains, combinational datapaths, and sequential logic circuits.
  • Deep Learning Systems — Building lightweight tensor computation engines, reverse-mode automatic differentiation, attention layers, and model quantization strategies from scratch.

Logic.cpp

A modern C++20 hardware simulation library for modeling digital logic circuits from electrical primitives to complex architecture components. Models wires, buses, clocks, tri-state buffers, gates, combinational datapaths, and sequential storage elements.
